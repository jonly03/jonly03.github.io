🚗 VIN Barcode Scan — prototype

Point the camera at the barcode on the driver's door-jamb label (the sticker you see with the door open). It reads the VIN exactly — no guessing like photo OCR. Everything happens on this phone: no photo is uploaded or saved.

Hold the barcode inside the frame, about 6–10 inches away. Give it a second to focus.

Ready.

In Case Core, this is where staff taps “Use this VIN” — the same confirmation step the photo-OCR result uses today.

How it works: open-source ZXing reader (WASM build) decodes the Code 39 barcode printed under the VIN on the certification label. A decoded VIN is then verified with the VIN's own built-in check digit (position 9), and the vehicle is identified with the free NHTSA vPIC decoder — the same public API family Case Core can call.
Limits: the door must be open; worn or dirty labels may not scan; photo OCR and manual typing stay as fallbacks.
